# CRM-Sales-Dashboard
CRM sales pipeline analysis using Excel and Power BI to evaluate pipeline performance, revenue, sales agents, products, and sales-cycle duration.

Project Overview
This project analyzes a CRM sales pipeline to understand opportunity performance, revenue generation, sales-agent performance, product performance, and sales-cycle duration.
The analysis was performed using Microsoft Excel for data cleaning and exploratory analysis and Power BI for interactive data visualization and dashboard development.

Business Questions

The analysis focuses on five key questions:

How is the sales pipeline performing?
How much revenue has been won?
How do sales agents perform across different metrics?
Which products generate the most revenue?
How long does it take to close an opportunity?
Tools Used
Microsoft Excel — data cleaning, calculated fields, PivotTables, exploratory analysis, and initial visualizations
Power BI — data visualization and interactive dashboard development
Analysis
1. Sales Pipeline Performance

The analysis examines:

Total opportunities
Won opportunities
Lost opportunities
Open opportunities
Win rate

2. Won Revenue

Won revenue is calculated from the Close Value of opportunities marked as Won.

Revenue is also analyzed over time to identify changes in sales performance.

3. Sales Agent Performance

Sales agents are compared using:

Total opportunities
Won opportunities
Won revenue
Win rate

4. Product Performance

Products are analyzed based on:

Number of opportunities
Won opportunities
Won revenue
Win rate

5. Sales Cycle

The sales cycle is calculated as the number of days between the engagement date and close date.

The analysis examines:

Average days to close
Median days to close
Sales-cycle duration by deal outcome
Sales-cycle duration by product

Dashboard

The Power BI dashboard provides an interactive view of the sales pipeline and allows users to explore the results across relevant dimensions.


Data Preparation

The data-cleaning process included checking for:

Missing values,
Duplicate records,
Inconsistent categorical values,
Invalid or unusual deal values,
Date inconsistencies, and
Invalid sales-cycle durations

Skills Demonstrated:

Data cleaning
Exploratory data analysis,
Excel formulas and PivotTables,
Business KPI analysis,
Data visualization,
Power BI dashboard development, and
Business reporting

Additional calculated fields were created for pipeline status, won revenue, and days to close.
